// API Reference

Office ConciergeAgent

An agent service that handles office administration. It issues ID badges and answers questions about office rules. An employee ID is required to issue a badge.

A2A 0.3.0 JSON-RPC 2.0 ● RUNNING

Endpoints

POST / A2A message handler
message/send sends a message. It handles badge requests that include an employee ID, as well as questions about office rules.
Request — badge issuance
{
  "jsonrpc": "2.0",
  "method":  "message/send",
  "id":      "1",
  "params": {
    "message": {
      "messageId": "msg-001",
      "role":      "user",
      "parts": [{
        "kind": "text",
        "text": "Please issue an ID badge for employee ID 12345"
      }]
    }
  }
}
Response 200
{
  "jsonrpc": "2.0",
  "id": "1",
  "result": {
    "parts": [{
      "kind": "text",
      "text": "### 🪪 ID badge request accepted\n..."
    }],
    "role": "agent"
  }
}
GET /.well-known/agent-card.json Agent Card
A2A-compliant agent metadata: agent name, skills, protocol version and provider. No authentication required.

Skills

SKILL badge-request
Supported operations: ID badge issuance, questions about office rules
Issuing a badge requires an employee ID (a name or email address is not a substitute)
Out of scope: loaner laptops → IT Provisioning Agent, employee ID lookup → Employee DB

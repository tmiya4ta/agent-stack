MCP Server + REST API

Employee DB
MCP Server

Provides access to the employee database. Supports both the MCP Streamable HTTP protocol and a REST API. It is backed by SQLite and seeds five records at startup.

MCP Streamable HTTP REST API SQLite ● RUNNING

Endpoints REST

GET /employee List employees

Returns every employee record ordered by id. No parameters.

Response 200
[
  { "id": 1, "name": "Taro Yamada", "email": "taro.yamada@example.com" },
  { "id": 2, "name": "Hanako Sato", "email": "hanako.sato@example.com" },
  // ... 5 records in total (seeded at startup)
]
POST /employee Add an employee

Adds a new employee record and returns the issued employee ID.

Request Body
{ "name": "Ichiro Tanaka", "email": "ichiro.tanaka@example.com" }
Response 200
{ "message": "Employee registered", "employeeId": 6 }

TABLE employee

  id     INTEGER PRIMARY KEY AUTOINCREMENT,
  name   TEXT    NOT NULL,
  email  TEXT    NOT NULL
);

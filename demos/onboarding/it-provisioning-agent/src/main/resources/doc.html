// API Reference

IT Provisioning
Agent

An agent service that provisions IT assets. It accepts loaner laptop orders and repair requests over the A2A 0.3.0 protocol. An employee ID is required.

A2A 0.3.0 JSON-RPC 2.0 ● RUNNING

Endpoints

POST / A2A message handler
message/send sends a message. For a request that includes an employee ID, it returns the result of the laptop order or repair arrangement as Markdown.
Request
{
  "jsonrpc": "2.0",
  "method":  "message/send",
  "id":      "1",
  "params": {
    "message": {
      "messageId": "msg-001",
      "role":      "user",
      "parts": [{
        "kind": "text",
        "text": "Please order a loaner laptop for employee ID 12345"
      }]
    }
  }
}
Response 200
{
  "jsonrpc": "2.0",
  "id": "1",
  "result": {
    "parts": [{
      "kind": "text",
      "text": "### 💻 Loaner laptop request accepted\n..."
    }],
    "role": "agent"
  }
}
GET /.well-known/agent-card.json Agent Card
A2A-compliant agent metadata: name, skills, protocol version and provider. No authentication required.

Skills

SKILL provisioningPC
Supported operations: new loaner laptop order, laptop repair request
Required parameter: employee ID (a name or email address is not a substitute)
Out of scope: badge issuance → Office Concierge Agent, employee ID lookup → Employee DB
